# 2D 画布工具（canvas2d）

> 2026-10-28 决定：站点**只做 2D**。分辨率固定 **800×600**，颜色只用 **256 色**，
> 文件只输出 **HTML5 类别**（HTML / CSS / JS / SVG / Canvas），**不含音频**。
>
> **默认呈现 = SVG**（首页与 `/watch/{id}` 保持现状）。画布版是**附加入口**，
> 不替换默认动画；**不做 3D「精细呈现」入口**。3D 路线（`graphics-roadmap.md`）仅作将来备选。

## 1. 这是什么

一个**我自己用**的确定性生成工具：把一篇 TXT 编译成一张自包含的 HTML5 画布动画。
你不需要操作它——它只在你允许的场合（我这边）用来出预览、出样品与做验收。

它借鉴 Blender 的**机制**（场景 → 图层 → 时间轴 → 关键帧 → 色彩管理），
但代码全部自研，不链接、不移植 Blender 的 GPL 代码。

## 2. 硬性约定

| 项 | 约定 |
|---|---|
| 画布 | `800 × 600`，4:3，像素即设计像素，禁止响应式缩放改变构图 |
| 颜色 | 固定 256 色：216 色立方（00/33/66/99/cc/ff）+ 40 级灰阶 |
| 形状 | 只允许圆、矩形、多边形、线段；禁止渐变、位图、滤镜 |
| 格式 | HTML5：HTML + 内联 CSS + 内联 JS + Canvas 2D |
| 音频 | 无音轨、无自动播放 |
| 确定性 | 同一篇 TXT，同一幕序、同一配色、同一动物 |

## 3. 四相（世界层）

四相就是四个世界层，每层一个招牌动物与主色：

| 四相 | 含义 | 招牌动物 | 主色（贴 256 色） |
|---|---|---|---|
| 原 | 自然界 | 狐狸（容易害怕） | `#ff6633` 橘 |
| 仙 | 灵气 | 小妖怪（喜欢笑着） | `#009999` 青 |
| 虫 | 色界生命 | 四足小鳄虫（会走路） | `#4c4c4c` 黑灰 |
| 人 | 欲界的六道 | 农夫（想着耕田有收成好养家） | `#cc9966` 黄 |

判定顺序：招牌动物直接命中 → 文本关键词得分最高 → 角色亲缘兜底。
「晨 / 昼 / 暮 / 夜」保留为**光时**（动画节奏），不再对外称四相。

## 4. 用法

```bash
# 生成演示作品的画布版
wayhug render2d demo

# 指定作品，输出到目录
wayhug render2d st_xxxxxxxx data/render2d

# 全部作品
wayhug render2d all data/render2d
```

在线入口：

- `GET /watch2d/{id}` —— 直接在浏览器里播放
- `GET /dl/{id}/canvas` —— 下载这份自包含 HTML（附件）

`?still=1&scene=N` 可定格到第 N 幕（与 SVG 版参数一致）。

## 5. 结构

| 文件 | 职责 |
|---|---|
| `palette.rs` | 256 色表、最近色、贴色（`snap_hex`） |
| `canvas2d.rs` | 场景编译（TXT → 幕）与画布渲染（HTML5） |
| `worldview.rs` | 四相定义、判定、公开视图与文稿校准统计 |
| `main.rs` | `render2d` 子命令（工具入口） |
| `web.rs` | `/watch2d/{id}` 与 `/dl/{id}/canvas` |

## 6. 验收

- `cargo test`：画布 800×600、无音频、四相幕序、贴色幂等
- 桌面 Chrome：`/watch2d/demo` 正常循环，点击暂停，空格同效
- 移动 500px：画布按 4:3 等比缩放，不溢出
- `?still=1&scene=3`：定格到第四幕
