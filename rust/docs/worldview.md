# 四相世界观 · 田字四分法

> 版本：worldview/0.1　｜　适用：wayhug.com 故事与动画引擎（Rust 版）
>
> 一句话：**四相描述光与时间，四属性描述动力与材质；两轴交叉成田字四象限，故事与动画都落在这四个格子里。**

---

## 1. 为什么是四分法

故事里最难统一的是「此刻是什么时候、角色在用什么力量」。四分法把这两件事拆成两条正交的轴：

- **四相（光与时间）**：晨 → 昼 → 暮 → 夜。它决定画面底色、墨色，也决定叙事处在哪一拍。
- **四属性（动力与材质）**：风 → 火 → 水 → 土。它决定画面里动作的方向与质感。

两轴交叉得到一个 2×2 的田字。每个格子同时拥有「一个时间」和「一种力量」，于是每一幕都能被唯一坐标描述，颜色、运动、情绪、叙事节拍都从坐标推导，而不是随手挑选。

```
┌──────────────┬──────────────┐
│  晨 · 风      │  昼 · 火      │
│  起 · 相遇    │  承 · 同行    │
│  漂移         │  上升         │
├──────────────┼──────────────┤
│  暮 · 水      │  夜 · 土      │
│  转 · 试炼    │  合 · 归处    │
│  下落         │  静止         │
└──────────────┴──────────────┘
```

## 2. 四象限规格

| 象限 | 相 | 属性 | 叙事拍 | 运动 | 底色 | 墨色 | 相重音 | 属性色 | 角色亲和 |
|------|----|------|--------|------|------|------|--------|--------|----------|
| 左上 | 晨 dawn | 风 wind | 起 · 相遇 | 漂移 | `#fff7e6` | `#2d2a26` | `#e8a33d` | `#ffb703` | 棉棉（兔） |
| 右上 | 昼 day | 火 fire | 承 · 同行 | 上升 | `#fff0e6` | `#33251f` | `#ff7e47` | `#ff7e47` | 小狐 |
| 左下 | 暮 dusk | 水 water | 转 · 试炼 | 下落 | `#eaf2f7` | `#22313d` | `#5d8aa8` | `#5d8aa8` | 憨熊 |
| 右下 | 夜 night | 土 earth | 合 · 归处 | 静止 | `#edeefa` | `#232538` | `#6b5b95` | `#8b6f47` | 墨鸮、喵先生 |

固定配对（田字对角线之外的默认组合）：

```
晨 → 风      昼 → 火      暮 → 水      夜 → 土
```

> 固定配对不是限制，而是**缺省值**：当文本没有明确的属性线索时，属性就取该相的固定配对，保证每一幕永远有完整坐标。

## 3. 判定规则（确定性、可复现）

引擎不依赖大模型，只用关键词计分 + 兜底链，保证同一段 TXT 永远得到同一套坐标。

### 3.1 四相

按关键词出现次数计分，取最高者：

| 相 | 关键词 |
|----|--------|
| 晨 | 晨、清晨、拂晓、曙光、日出、醒来、早晨、曦 |
| 昼 | 正午、中午、白昼、阳光、太阳、晴、午、日头 |
| 暮 | 黄昏、傍晚、暮、夕、晚霞、日落、斜阳 |
| 夜 | 夜、月、星、深夜、梦、灯、黑暗、午夜 |

### 3.2 四属性

| 属性 | 关键词 |
|------|--------|
| 风 | 风、云、飞、飘、呼吸、轻、翼 |
| 火 | 火、暖、光、热、燃、灯、亮 |
| 水 | 水、雨、河、海、泪、雪、溪、湖 |
| 土 | 土、山、石、树、林、根、屋、路 |

### 3.3 兜底链

```
四相：文本关键词
      ↓ 无命中
      角色亲和（仅当文本命中属性词时启用，避免角色噪声）
      ↓ 仍无
      情绪兜底
      ↓ 仍无
      晨（dawn）

四属性：文本关键词
        ↓ 无命中
        该相的固定配对
```

情绪 → 四相兜底：

| 情绪 | 相 |
|------|----|
| 明快 joyful、惊讶 surprised | 昼 |
| 怀旧 nostalgic、沉思 thoughtful | 暮 |
| 淡淡忧伤 melancholy | 夜 |
| 平静 calm 及其他 | 晨 |

### 3.4 角色亲和

| 角色 | 相 | 属性 | 颜色 |
|------|----|------|------|
| 小狐 fox | 昼 | 火 | `#ff7e47` |
| 墨鸮 owl | 夜 | 风 | `#6b5b95` |
| 棉棉 rabbit | 晨 | 土 | `#ffb6c1` |
| 憨熊 bear | 暮 | 土 | `#8b6f47` |
| 喵先生 cat | 夜 | 水 | `#708090` |

角色识别关键词：狐/狐狸/小狐、鸮/猫头鹰/墨鸮、兔/棉棉、熊/憨熊、猫/喵/喵先生。

## 4. 故事模式

### 4.1 TXT 输入约定

- 第一行可以是标题：长度 ≤ 24 字、不含句末标点、不含换行，即视为标题；否则从首句截取 16 字作为标题。
- 空行分段。段落 ≤ 96 字符时，一段 = 一幕；超过 96 字符按句切分，最多 24 幕。
- 正文按句切分保留标点，用于台词气泡逐句出现。

### 4.2 每一幕的固定结构

```json
{
  "id": 0,
  "text": "清晨，小狐在森林里捡到一封没有地址的信。",
  "animal": "fox",
  "mood": "thoughtful",
  "phase": "dawn",
  "element": "wind",
  "palette": {
    "bg": "#fff7e6",
    "ink": "#2d2a26",
    "accent": "#2f9e77",
    "animalColor": "#ff7e47"
  }
}
```

- `bg` / `ink` 来自四相；
- `accent` 来自情绪（明快 `#ff9f43`、怀旧 `#6b5b95`、沉思 `#2f9e77`、惊讶 `#e0567a`、淡淡忧伤 `#5d8aa8`、平静 `#708090`）；
- `animalColor` 来自角色。

### 4.3 叙事四拍

四相同时就是叙事节拍：

```
起（晨·相遇） → 承（昼·同行） → 转（暮·试炼） → 合（夜·归处）
```

一个完整故事建议至少覆盖三拍；如果四拍齐全，动画会在观感上形成「亮 → 暖 → 低 → 静」的自然呼吸。

## 5. 动画模式

- **时长**：每幕 4.2 秒，总时长 = 幕数 × 4.2s。
- **实现**：CSS `@keyframes sc{i}` 逐幕控制显示/隐藏，`animation-duration: var(--total)`，纯 CSS 播放，无 JS 依赖。
- **角色**：纯 SVG 几何动物（圆、椭圆、三角、路径），无位图、无渐变、无外部资源。
- **版式**：动物 190px、台词气泡最大 720px；移动端动物 136px；单文件 HTML 自包含 CSS。
- **定格**：`/watch/{id}?still=1&scene=N` 可定格到指定幕，便于截图、海报与验收。
- **扁平不变式**：只允许四相底色、墨色、情绪重音色与角色色；禁止渐变、阴影堆叠、位图。

## 6. 素描原画喂养

素描是这个世界观的「视觉证据」：它不直接生成动画，而是作为参考样本进入原画库，用于校准四相与属性，并为后续角色设定、分镜与色板扩展提供依据。

### 6.1 两个入口

| 入口 | 用途 |
|------|------|
| 网页后台 `/studio` → 原画喂养 | 单张上传，填标题/四相/四属性/标签/备注 |
| 命令行 `wayhug ingest-sketch <文件> [标题] [四相] [四属性]` | 单张快速入库 |
| 命令行 `wayhug ingest-dir <目录>` | 批量喂养一个目录（png/jpg/jpeg） |

### 6.2 处理流程

```
图片字节
  → 魔数校验（仅 PNG / JPEG，≤ 12MB，边长 ≤ 12000px）
  → sha256 指纹（取前 10 位作为 sk_ 编号，天然去重）
  → 缩放到 48×48
  → 5 bit/通道量化取主色（最多 4 个，色距 > 1600 才收录）
  → 平均亮度 + 冷暖（R − B）→ 建议四相 / 四属性
  → 落盘 data/sketches/{id}.{png|jpg}
  → 元数据写入 data/wayhug.json
```

四相建议算法：

| 条件 | 建议 |
|------|------|
| 亮度 ≥ 140 且偏暖 | 昼 · 火 |
| 亮度 ≥ 140 且偏冷 | 晨 · 风 |
| 亮度 < 140 且偏暖 | 暮 · 水 |
| 亮度 < 140 且偏冷 | 夜 · 土 |

人工指定的四相/四属性优先于自动建议；自动建议同时保留在 `suggestedPhase` / `suggestedElement` 字段里，便于后续对比校准。

### 6.3 原画元数据

```
id, title, phase, element, tags[], note,
file, mime, bytes, sha256, width, height,
palette[], suggestedPhase, suggestedElement, createdAt
```

### 6.4 使用原则

1. 原画只进后台与数据文件，**不进入公众页面**。
2. 原画用于校准坐标：当人工标注与自动建议不一致时，以人工为准，并把原画作为该象限的参考样本。
3. 后续角色设定（造型、线条、配色）应优先参考同一象限内已入库的原画，保持「同相同貌」。

---

## 7. 不变式（改动代码时必须守住）

1. 每一幕必须有 `phase` 与 `element`，且值来自四相/四属性的枚举。
2. 缺属性时只能取该相的固定配对，不能随机。
3. 颜色只能来自：四相底色/墨色、情绪重音色、角色色。
4. JSON 是唯一事实源；CSS、HTML5、A4 证书都从它派生。
5. 公众页面只呈现「看 / 写 / 领 / 寄」；后台能力全部收在 `/studio`。

## 8. 内容边界与文稿优先

### 8.1 硬边界

- **不涉及宗教**：寺庙、教堂、祈祷、教义、神职等一律不收录。
- **不涉及政治**：政府、政党、选举、领导人、政治运动等一律不收录。
- 闸门实现在 `src/guard.rs`，网页生成、邮件投稿、命令行文稿导入三处共用同一套关键词与提示语。

### 8.2 文稿是唯一来源

动画、四相坐标、角色与证书都必须从作者写下的 TXT 文稿派生，而不是由模板自行编造。

- 文稿放在仓库根目录 `manuscripts/`，用 `wayhug ingest-stories ../manuscripts` 导入；
- 首页「文稿集合」随导入自动更新；
- 首页「文稿校准」条与 `/api/corpus` 每次请求都按已收录文稿逐幕重算四相占比，不写死比例；
- 世界观是被文稿**逐步校准**的：先有文稿，再调整关键词与色板，最后同步本文档；
- 不为单篇文稿改坐标系，避免世界观反过来限制写作。

### 8.3 声音

网站只有动画：没有音乐、没有音效、没有自动播放的音频。
