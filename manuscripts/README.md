# 文稿集合（manuscripts）

这里是 wayhug 的**唯一故事来源**。动画、四相坐标、角色与证书都由这里的 TXT 文稿派生。

## 怎么放

- 一篇文稿一个 `.txt` 文件，文件名随意（建议用序号 + 短标题，方便排序）。
- 第一行可以写标题（≤ 24 字、不含句末标点）；不写则自动从首句截取。
- 空行分段；每段不超过 96 字时一段变一幕，超过则按句切分，最多 24 幕。
- 角色名直接写：小狐 / 墨鸮 / 棉棉 / 憨熊 / 喵先生。

## 怎么进站

```bash
cd rust
cargo run --release -- ingest-stories ../manuscripts
```

导入后：

- 作品进入 `/watch/{id}` 与首页「文稿集合」；
- 首页「文稿校准」条自动重算四相占比（也可看 `/api/corpus`）；
- 该作品出现在「领」的下拉框里，可生成 A4 体验权证书；
- 同一篇文稿重复导入不会产生重复记录（按内容指纹去重）。

> 线上导入：`cd /opt/wayhug.com/rust && ./target/release/wayhug ingest-stories ../manuscripts`，随后 `sudo systemctl restart wayhug-rust.service`，让常驻服务重新加载数据。

## 内容边界（硬规则）

- **不涉及宗教**：寺庙、教堂、祈祷、教义、神职等一律不收录。
- **不涉及政治**：政府、政党、选举、领导人、政治运动等一律不收录。
- 只写故事、动物、四季、关系、试炼与归处。
- 闸门代码在 `rust/src/guard.rs`，网页、邮件、命令行三处共用。

## 世界观怎么迭代

四相（晨 / 昼 / 暮 / 夜）× 四属性（风 / 火 / 水 / 土）是故事的坐标系。
文稿积累后，如果出现新的场景类型或新的叙事节拍：

1. 先写进文稿，观察连续几篇是否稳定；
2. 再更新 `rust/src/worldview.rs` 的关键词与色板；
3. 同步更新 `rust/docs/worldview.md` 的对照表。

不要为了单篇文稿去改坐标系；坐标系是被文稿逐步校准的，而不是反过来规定文稿。

## 声音

网站只有动画，没有音乐、没有音效、没有自动播放的音频。
